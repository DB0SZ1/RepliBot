# X Reply Guy Bot - Intelligent Growth System

## 🎯 Project Overview

An AI-powered X (Twitter) bot that learns authentic Nigerian communication styles, engages organically, and grows your account without triggering spam filters. The bot uses OpenRouter for advanced reasoning and operates within X's free tier API limits.

### Core Philosophy
- **Learn First, Act Later**: 2-week silent learning period analyzing posts
- **Nigerian Authenticity**: Understands shitposts, ragebait, local humor, and valuable content
- **Continuous Learning**: Adapts throughout its lifetime using engagement metrics
- **Predictive Intelligence**: Knows what to jump on based on traction predictions
- **Human-Like Behavior**: Mimics real user patterns to avoid detection

## 🚀 Installation & Setup

### Prerequisites
- Python 3.9+
- X Developer Account (Free Tier)
- OpenRouter API Key
- Git

### Step 1: Clone & Install

```bash
git clone <your-repo-url>
cd x-reply-bot
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate
pip install -r requirements.txt
```

### Step 2: Configure X API

1. Go to [X Developer Portal](https://developer.x.com)
2. Create a new app (Free tier)
3. Generate API keys (API Key, API Secret, Bearer Token)
4. Copy `config/x_credentials.json.example` to `config/x_credentials.json`:

```json
{
  "api_key": "your_api_key_here",
  "api_secret": "your_api_secret_here",
  "bearer_token": "your_bearer_token_here",
  "access_token": "your_access_token_here",
  "access_token_secret": "your_access_token_secret_here"
}
```

### Step 3: Configure OpenRouter

1. Get API key from [OpenRouter](https://openrouter.ai)
2. Copy `config/openrouter_config.json.example` to `config/openrouter_config.json`:

```json
{
  "api_key": "your_openrouter_key_here",
  "model": "anthropic/claude-3.5-sonnet",
  "temperature": 0.8,
  "max_tokens": 2000
}
```

## 🧠 How It Works

### Phase 1: Learning Mode (Days 1-14)

**No write actions performed. Bot observes silently.**

```bash
python learn_mode.py
```

**What happens:**
1. **Post Collection**: Scrapes 500+ posts from target accounts
2. **Style Analysis**: AI analyzes:
   - Sentence structure (short vs long)
   - Emoji usage patterns
   - Nigerian pidgin integration
   - Humor types (sarcasm, wordplay, memes)
   - Topic transitions
3. **Engagement Patterns**: Studies:
   - What gets likes/RTs
   - Best posting times
   - Hashtag effectiveness
   - Thread vs single tweet performance
4. **Personality Synthesis**: Builds unique voice by blending target accounts weighted by config

### 2. Traction Prediction Algorithm

**Metrics Analyzed:**
- Author's follower count
- Historical engagement rate
- Time posted (vs optimal times)
- Topic relevance to trending hashtags
- Sentiment analysis (positive/negative/neutral)
- Media presence (images/videos increase engagement)

**Scoring Formula:**
```python
traction_score = (
    (author_followers / 1000) * 0.2 +
    author_engagement_rate * 0.3 +
    topic_relevance * 0.25 +
    time_optimality * 0.15 +
    media_bonus * 0.1
) * 100
```

**Decision Logic:**
- Score 0-30: Skip
- Score 30-60: Consider if slow day
- Score 60-80: Good opportunity
- Score 80-100: High priority action

### 3. Human-Like Behavior Patterns

**Randomization to Avoid Detection:**
- Action intervals: Not exactly 1 hour apart (randomized 45-90 mins)
- Response time: Delayed by 2-15 minutes (humans don't reply instantly)
- Activity gaps: Simulates sleep (inactive 12am-6am WAT)
- Weekend behavior: Reduced activity Sundays
- Typo injection: Occasional intentional typos (2% of posts)

## 🛡️ Safety & Compliance

### Anti-Spam Measures

1. **Content Diversity Check**: No two posts within 24h can be >70% similar
2. **Engagement Pacing**: Max 3 replies to same user per day
3. **Hashtag Limits**: Max 2 hashtags per post
4. **Link Caution**: Max 1 link per 5 posts
5. **Mention Limits**: Max 1 @mention per post

### X Policy Compliance

- ✅ Never reply without context (no keyword spamming)
- ✅ No automated liking (endpoint disabled in free tier anyway)
- ✅ Respect opt-outs (if user says "stop", blacklist them)
- ✅ Rate limit respect (17/day hard coded)
- ✅ No misleading identity (bio clearly states it's a bot)

### Error Handling

```python
# All API calls wrapped in retry logic
@retry(tries=3, delay=60, backoff=2)
def post_tweet(content):
    try:
        response = x_client.post_tweet(content)
        log_action('post', response.id, content)
        return response
    except RateLimitError:
        logger.warning("Rate limit hit, pausing...")
        pause_until_reset()
    except APIError as e:
        logger.error(f"API error: {e}")
        alert_admin(e)
        raise
```

## 🔍 Troubleshooting

### Common Issues

**1. Rate Limit Hit Before 17 Actions**
- **Cause**: Counting error or API endpoint confusion
- **Fix**: Check `data/action_log.json` for duplicate entries
- **Code**: `src/core/rate_limiter.py` line 45

**2. Bot Sounds Robotic**
- **Cause**: Insufficient learning data
- **Fix**: Run `learn_mode.py` for additional week
- **Increase**: `posts_to_collect` in config from 500 to 2000

**3. Low Engagement**
- **Cause**: Posting at wrong times or topics
- **Fix**: Review `data/engagement_metrics.json` best times
- **Adjust**: `active_hours` in config

**4. OpenRouter Timeout**
- **Cause**: Model taking too long (>30s)
- **Fix**: Switch to faster model in config
- **Alternative**: `openai/gpt-4o-mini` (faster, cheaper)

**5. X API 401 Unauthorized**
- **Cause**: Expired tokens
- **Fix**: Regenerate tokens in X Developer Portal
- **Update**: `config/x_credentials.json`
